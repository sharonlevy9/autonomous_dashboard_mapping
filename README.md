# Autonomous dashboard mapping

Component dashboard + component cards for the autonomous cave tool (HIT industrial design studio).

- `dashboard/src/data.json` : the single data source (components, dimensions, rules)
- `dashboard/src/template.html` + `build.py` : the app source; build with `python3 build.py three.min.js OrbitControls.js out.html`
- `dashboard/components-dashboard.html` : the current built, offline file
- `dashboard/chatbot/` : Q&A chatbot
- `components/` : 3D legs, wiring schematic, 1:1 nets
